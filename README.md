# TV Empire Chronicle — Initial Pass

A playable Vite + React prototype for a narrative-heavy television CEO simulation.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Included in this pass

- Executive dashboard and weekly simulation
- Editable prime-time schedule
- Creative development pipeline and show creator
- LinkedIn-style talent market with offers and responses
- Nielsen-style ratings center
- Advertising marketplace and contract negotiation
- Marketing campaign builder
- Finance portal with program-level economics
- Production/operations control tower
- Weekly industry Chronicle
- Lightweight local save state

## Notes

This is a vertical-slice prototype rather than the final economic model. It is deliberately designed as a network of realistic company tools, with a shared simulated world underneath.
